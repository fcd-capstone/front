# FCD 관제 대시보드

다중 센서 기반 제조 작업환경 이상 원인 판별 및 대응 우선순위 관제 시스템의 프론트엔드 저장소입니다.

## 개발 범위

- 노드 A·B의 실시간 센서값 및 상태 표시
- 이상 원인, 신뢰도, 판단 근거 및 대응 우선순위 표시
- 센서 시계열 그래프 및 이상 이벤트 이력 조회
- 현장 알림 및 처리 상태 보고 화면
- 실험 라벨 조회 및 수집 데이터 재생 시연 화면

## 데이터 처리 기준

- 노드는 `node-a`(기준), `node-b`(도어 쪽) 두 개입니다.
- 노드 B의 `co2`, `dp`는 미설치 센서이므로 `null`이며, 나머지 측정 필드도 일시적으로 `null`일 수 있습니다.
- 결측값을 0으로 변환하지 않습니다.
- `eco2`(추정 CO₂)와 `co2`(실측 CO₂)를 구분합니다.
- 시간 정렬은 Unix 초 단위의 `ts`를 기준으로 합니다. JavaScript 날짜 변환 시 1000을 곱합니다.
- 메시지 고유 키는 `node + boot + seq`입니다. 파일의 첫 `seq`가 1일 필요는 없습니다.
- 샘플 CSV는 형식 확인용이며 정상 기준값이나 경보 임계값으로 사용하지 않습니다.
- 저장·보정·판별·우선순위 계산과 CSV 재생은 백엔드가 담당하며, API 응답 형식과 실시간 갱신 방식은 협의 후 확정합니다.
